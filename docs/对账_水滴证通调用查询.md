# 水滴（证通）上游调用对账查询

用于把我们对水滴的实际调用，与水滴给出的对账 Excel（如 `存疑税号.xlsx`，两个 sheet：`票` / `税`，列 `nsrsbh, create_time`）逐条核对。

## 1. 口径

| 水滴 Excel | 我们这边 |
| --- | --- |
| 水滴 / 证通（`cisp.zenitera.com`） | `upstream_call.provider = 'entcredit'` |
| `票` sheet | `source_label IN ('invoice1','invoice2')`，产品 P0130081 / P0130083（发票数据聚合） |
| `税` sheet | `source_label IN ('tax1','tax2')`，产品 P0130082 / P0130084（税务数据聚合） |
| `nsrsbh` | `audit_log.credit_code`（按 `request_id` 关联） |
| `create_time`（北京时间） | `upstream_call.created_at AT TIME ZONE 'Asia/Shanghai'` |
| 水滴订单号 | `upstream_call.upstream_uid`（证通返回的 `orderNo`） |

`upstream_call.status` 含义：

- `ok`：查得（证通 `upstream_code = 001`）
- `empty`：查无（`upstream_code = 999`）
- `error`：调用失败（超时、网关错误、E 开头错误码等）
- `skipped`：**没有发出请求**（更高优先级源已满足、已请求过等），对账时必须排除

part1 与 part2 数据重复，relay 启动时只保留 part2，所以实际行基本都是 `invoice2` / `tax2`；下面的 SQL 两种都兼容。

`upstream_call.created_at` 是 relay 落库时间，与水滴记录的时间通常相差几秒以内，所以按「税号 + 维度 + 时间就近」匹配，不要求时间完全相等。

## 2. 运行方式

库只在阿里云 ECS 内网可达（本机直连 RDS 会被白名单拒绝）。在 ECS 上用 psql 连生产库执行，连接信息见 `config.aliyun.prod.yaml` 的 `database` 段。

下面的 SQL 都用 psql 变量指定时间范围，先设置：

```sql
\set t_from '2026-09-01 00:00:00'
\set t_to   '2026-10-01 00:00:00'
```

## 3. 调用明细（全部实际发出的请求）

```sql
SELECT
    CASE WHEN uc.source_label LIKE 'invoice%' THEN '票' ELSE '税' END   AS 维度,
    a.credit_code                                                       AS nsrsbh,
    to_char(uc.created_at AT TIME ZONE 'Asia/Shanghai',
            'YYYY-MM-DD HH24:MI:SS')                                    AS create_time,
    uc.source_label,
    uc.status,
    uc.upstream_code,
    uc.upstream_msg,
    uc.upstream_uid                                                     AS 水滴订单号,
    uc.latency_ms,
    l.name                                                              AS 客户,
    uc.app_key,
    uc.request_id
FROM upstream_call uc
LEFT JOIN audit_log a ON a.request_id = uc.request_id
LEFT JOIN license   l ON l.app_key    = uc.app_key
WHERE uc.provider = 'entcredit'
  AND uc.status  <> 'skipped'
  AND uc.created_at >= (:'t_from')::timestamp AT TIME ZONE 'Asia/Shanghai'
  AND uc.created_at <  (:'t_to')::timestamp   AT TIME ZONE 'Asia/Shanghai'
ORDER BY 维度, uc.created_at;
```

导出 CSV 给 Excel 用（`\copy` 必须写在一行内，且不展开 `:'t_from'` 这类变量，时间要直接写成字面量）：

```sql
\copy (<上面的 SELECT 压成一行，去掉末尾分号，时间换成 '2026-09-01 00:00:00' 这样的字面量>) TO '/tmp/水滴调用明细.csv' WITH (FORMAT csv, HEADER)
```

## 4. 汇总（按维度 × 结果）

```sql
SELECT
    CASE WHEN uc.source_label LIKE 'invoice%' THEN '票' ELSE '税' END AS 维度,
    uc.status,
    count(*)                         AS 调用次数,
    count(DISTINCT a.credit_code)    AS 去重税号数
FROM upstream_call uc
LEFT JOIN audit_log a ON a.request_id = uc.request_id
WHERE uc.provider = 'entcredit'
  AND uc.status  <> 'skipped'
  AND uc.created_at >= (:'t_from')::timestamp AT TIME ZONE 'Asia/Shanghai'
  AND uc.created_at <  (:'t_to')::timestamp   AT TIME ZONE 'Asia/Shanghai'
GROUP BY 1, 2
ORDER BY 1, 2;
```

## 5. 与 Excel 同形状的清单（每个税号每个维度一行）

水滴 Excel 里同一 sheet 内税号不重复，所以这里也按「维度 + 税号」去重，取首次调用时间，并带上调用次数和是否有过查得，方便判断水滴是按首次调用还是按查得计费。

```sql
SELECT
    CASE WHEN uc.source_label LIKE 'invoice%' THEN '票' ELSE '税' END AS 维度,
    a.credit_code                                                     AS nsrsbh,
    to_char(min(uc.created_at) AT TIME ZONE 'Asia/Shanghai',
            'YYYY-MM-DD HH24:MI:SS')                                  AS 首次调用时间,
    to_char(min(uc.created_at) FILTER (WHERE uc.status = 'ok')
            AT TIME ZONE 'Asia/Shanghai', 'YYYY-MM-DD HH24:MI:SS')    AS 首次查得时间,
    count(*)                                                          AS 调用次数,
    count(*) FILTER (WHERE uc.status = 'ok')                          AS 查得次数,
    count(*) FILTER (WHERE uc.status = 'empty')                       AS 查无次数,
    count(*) FILTER (WHERE uc.status = 'error')                       AS 失败次数,
    string_agg(DISTINCT l.name, ' / ')                                AS 客户
FROM upstream_call uc
LEFT JOIN audit_log a ON a.request_id = uc.request_id
LEFT JOIN license   l ON l.app_key    = uc.app_key
WHERE uc.provider = 'entcredit'
  AND uc.status  <> 'skipped'
  AND uc.created_at >= (:'t_from')::timestamp AT TIME ZONE 'Asia/Shanghai'
  AND uc.created_at <  (:'t_to')::timestamp   AT TIME ZONE 'Asia/Shanghai'
GROUP BY 1, 2
ORDER BY 1, 3;
```

## 6. 直接在库里和 Excel 比对

### 6.1 导入 Excel

把 `存疑税号.xlsx` 两个 sheet 各存成 CSV（保留表头 `nsrsbh,create_time`），传到 ECS 的 `/tmp/sd_piao.csv`、`/tmp/sd_shui.csv`，然后：

```sql
CREATE TEMP TABLE sd_bill (dim text, nsrsbh text, create_time timestamp);
CREATE TEMP TABLE sd_raw  (nsrsbh text, create_time timestamp);

\copy sd_raw FROM '/tmp/sd_piao.csv' WITH (FORMAT csv, HEADER)
INSERT INTO sd_bill SELECT '票', trim(nsrsbh), create_time FROM sd_raw;
TRUNCATE sd_raw;

\copy sd_raw FROM '/tmp/sd_shui.csv' WITH (FORMAT csv, HEADER)
INSERT INTO sd_bill SELECT '税', trim(nsrsbh), create_time FROM sd_raw;

SELECT dim, count(*) FROM sd_bill GROUP BY dim;   -- 应为 票 92、税 106
```

### 6.2 我方调用落成临时表

```sql
CREATE TEMP TABLE our_call AS
SELECT
    CASE WHEN uc.source_label LIKE 'invoice%' THEN '票' ELSE '税' END AS dim,
    a.credit_code                                    AS nsrsbh,
    (uc.created_at AT TIME ZONE 'Asia/Shanghai')     AS call_time,
    uc.status, uc.upstream_code, uc.upstream_uid,
    l.name AS customer, uc.request_id
FROM upstream_call uc
LEFT JOIN audit_log a ON a.request_id = uc.request_id
LEFT JOIN license   l ON l.app_key    = uc.app_key
WHERE uc.provider = 'entcredit'
  AND uc.status  <> 'skipped'
  AND uc.created_at >= (:'t_from')::timestamp AT TIME ZONE 'Asia/Shanghai'
  AND uc.created_at <  (:'t_to')::timestamp   AT TIME ZONE 'Asia/Shanghai';
```

### 6.3 水滴每一行在我方的对应调用

对每条水滴记录，找同维度、同税号、时间最接近的一次我方调用。`时间差_秒` 在几秒内即为同一次调用；为空表示我方没有这次调用。

```sql
SELECT
    b.dim                                          AS 维度,
    b.nsrsbh,
    b.create_time                                  AS 水滴时间,
    c.call_time                                    AS 我方时间,
    round(abs(extract(epoch FROM c.call_time - b.create_time))) AS 时间差_秒,
    c.status                                       AS 我方结果,
    c.upstream_code,
    c.upstream_uid                                 AS 水滴订单号,
    c.customer                                     AS 客户,
    CASE
        WHEN c.nsrsbh IS NULL THEN '我方无此调用'
        WHEN abs(extract(epoch FROM c.call_time - b.create_time)) > 60 THEN '时间对不上（>60秒）'
        WHEN c.status = 'error' THEN '我方记为失败'
        WHEN c.status = 'empty' THEN '我方记为查无'
        ELSE '一致'
    END                                            AS 对账结论
FROM sd_bill b
LEFT JOIN LATERAL (
    SELECT *
    FROM our_call o
    WHERE o.dim = b.dim AND o.nsrsbh = b.nsrsbh
    ORDER BY abs(extract(epoch FROM o.call_time - b.create_time))
    LIMIT 1
) c ON TRUE
ORDER BY 对账结论, b.dim, b.create_time;
```

结论汇总：

```sql
-- 把上一条 SELECT 包成子查询 t
SELECT 维度, 对账结论, count(*) FROM (<6.3 的 SELECT，去掉 ORDER BY>) t GROUP BY 1, 2 ORDER BY 1, 2;
```

### 6.4 反向：我方有调用但水滴 Excel 里没有

```sql
SELECT o.dim AS 维度, o.nsrsbh, o.call_time, o.status, o.upstream_code, o.upstream_uid, o.customer
FROM our_call o
WHERE NOT EXISTS (
    SELECT 1 FROM sd_bill b WHERE b.dim = o.dim AND b.nsrsbh = o.nsrsbh
)
ORDER BY o.dim, o.call_time;
```

`存疑税号.xlsx` 只是水滴挑出来的存疑部分，不是全量账单，这一步的结果只在拿到水滴全量账单时才有对账意义。

## 7. 常见差异的判断

- **我方无此调用**：先去掉时间条件，用税号在 `our_call` / `upstream_call` 里搜一遍，排除跨月边界或时区问题；仍没有，就是水滴多记了。
- **我方记为失败（error）**：看 `upstream_code` / `upstream_msg`。如果是我方超时但水滴实际处理了，水滴会有记录、我方拿不到数据，这类需要和水滴协商是否计费。
- **我方记为查无（empty，code 999）**：按商务条款确认水滴是否对查无计费。
- **税号为空**：`audit_log` 没关联上（极少，通常是落库失败）。用 `upstream_call.request_id` 去应用日志里查。
